# Six Passports · Interactive Lab

Upload everything in this folder to the root of a GitHub repository, keeping the `uploads` folder next to `index.html`.

1. On GitHub, create a new public repository (for example `six-passports`).
2. Click **Add file → Upload files**, drag in `index.html`, `README.md`, and the `uploads` folder, then click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, and click **Save**.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/six-passports/`.

Notes
- The briefing maps load map data from the internet (jsdelivr.net and unpkg.com). If your school filter blocks those sites, ask IT to allow them.
- Student progress is saved in each browser, not on GitHub.
